- 콘텐츠 전략 인사이트: 이미지 기반 텍스트 생성 서비스에서 멀티모달 모델이 시각적 맥락을 무시하지 않도록 프롬프트 설계나 모델 튜닝 전략을 최적화하는 데 활용됨.
- 원문 링크: https://arxiv.org/abs/2608.23570
